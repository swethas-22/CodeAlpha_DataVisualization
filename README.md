# CodeAlpha_DataVisualization

## 📌 Overview
This repository contains **Task 3: Data Visualization** completed as part of the **CodeAlpha Data Analytics Internship**. The project transforms raw restaurant billing data into clear charts and graphs to uncover customer spending and tipping patterns.

## 🛠️ Tools & Libraries
* **Language:** Python
* **Libraries:** Pandas, Matplotlib, Seaborn
* **Environment:** Google Colab / Jupyter Notebook

## 📊 Visualizations Created
1. **Bar Chart:** Compared average total bill amounts across different days of the week.
2. **Scatter Plot:** Analyzed the relationship between total bill and tip amount across lunch and dinner shifts.
3. **Pie Chart:** Illustrated the customer traffic split between lunch and dinner.
4. **Correlation Heatmap:** Highlighted statistical correlations between bill size, tip amount, and party size.

## 💡 Key Insights for Decision-Making
* **Staffing Optimization:** Dinner drives **72.1%** of total traffic, and weekend bills are highest, showing where restaurant staffing should be concentrated.
* **Revenue Correlation:** Total bill and tip amounts share a strong positive correlation (**0.68**), meaning upselling directly increases server tips.
